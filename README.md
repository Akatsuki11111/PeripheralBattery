# PeripheralBattery

Windows 外设电量托盘工具，使用 Python / PySide6。


## 本次双版本发布

- **v2.5.0 正式版**：没有电量适配实验、长期观察和实验映射运行模块。
- **v2.5.1-experimental.1 实验版**：保留分步采样、长时间观察和本地实验映射。

两版都包含休眠电量时标、手柄识别、标准电池通道和精简打包。版本后缀遵守 SemVer；实验版放在下一修订号的预发布下，便于现有更新器区分顺序。默认同时只能运行一个版本，共用设置和可信历史；正式版不加载旧实验推测，原实验文件仍留在本机。仅切换“更新通道”不会立即改变当前安装版本，仍需完成对应版本的更新或运行所下载的程序；不会自动降级。

正式版新安装默认检查正式通道；实验版新安装默认包含预发布。已有用户的通道偏好保留。GitHub 的正式 Release 与 Pre-release 分开发布，稳定分支为 stable，实验开发为 main；标签和 Release 始终与各自源码版本对应。

## v2.5 手柄与休眠时标

休眠或连接待确认时，设备行显示最后一次有效电量及“上次 HH:mm:ss”；跨日显示月日。刷新不会改写这个时间。恢复有效应答后恢复实时显示，物理拔除后仍不显示该设备。

目录新增 22 个手柄品牌和 539 个明确型号标识，总计 77 品牌、859 个明确 ID。支持通用 HID 手柄类别识别与 XInput / Windows.Gaming.Input 电池查询，以及部分 Sony、Nintendo、八位堂型号的被动电池字段解析。品牌/型号识别与电池协议支持分开，四档电量不伪装成精确百分比，分档读数不参与可信最低电量、提醒与续航预测。详见 [GAMEPADS.md](GAMEPADS.md)。

北通 KP50B 与墨将彩虹2完成接入、去重、控制接口和标准通道实机核对，但当前模式仍缺少已验证的专用百分比协议。XInput 的 WIRED 与固定 1000/1000 容量报告不被直接采信为满电或无电池。其他手柄解码有测试覆盖，尚未逐一实物验证。

## 精简打包

移除未使用的 Qt Quick/QML、PDF、软件 OpenGL、无关插件和翻译，保留 Widgets、PNG/ICO/SVG 图标、系统字体、IPC、HTTPS 更新和原设备协议。两版仍为无需另装 Python 的独立 EXE，约 28.6 MB；原 v2.4.1 为 48.75 MB，减少约 41%。10 MB 目标未达到；在保留 CPython/PySide6 独立运行的条件下，核心运行库已超过该预算。没有通过下载额外运行库来隐藏体积。

```powershell
.\build.ps1 -Channel stable
.\build.ps1 -Channel experimental
.\build.ps1 -Channel both
```

打包设置在 PeripheralBattery.spec，release.json 描述源码运行通道，构建时生成各通道的独立版本数据和 Windows 版本资源。173 项回归测试通过；两版均核对了模块清单、独立启动、超时隔离、原生界面和 GitHub HTTPS 查询。正式包确认不含实验模块。

## 使用

在 [Releases](https://github.com/Akatsuki11111/PeripheralBattery/releases) 下载带版本号的 EXE。程序在通知区域显示有效设备电量，点击打开设备列表。首次运行 Windows 可能提示未签名应用；程序尚无商业代码签名。

支持按型号识别、部分设备电量与充电状态、5/15/30/60 秒刷新、有线无电池标记和设备管理。品牌识别不等于该品牌所有型号已支持电量。详情与可用选项以各版本代码为准。

## 实验功能

v2.2.0 起提供分步协议检查；v2.3.0 起提供 1/2 小时观察。实验只使用已知状态查询或描述符声明的 Feature GET，不读取键鼠 Input 数据，不扫描私有配置命令。未知型号不一定提供电量报告，长时间观察不保证完成适配。实验候选需手动确认，显示带 ? 的推测读数，不参与可信最低电量与提醒。未完成未知硬件的两小时实物验证。

v2.3.1 修正通用接收器型号展示，增加瓦尔基里官方目录标识和分项 HID 描述诊断。共享 OEM 标识不强制归为某品牌；具体未适配硬件仍需要 VID/PID 和诊断报告。

## 从源码运行与构建

Windows 10/11，Python 3.14。建议使用独立虚拟环境。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
python -m unittest discover -s tests
```

运行 `build.ps1` 构建对应版本的 EXE。后台查询在可终止的独立进程中运行。实验和缓存数据保存在当前用户的 `.peripheral-battery` 目录，只在本机使用；请先审阅诊断内容再分享。

## v2.4.0 软件内更新

旧于 v2.4.0 的程序需要先从 Release 手动升级一次。源码运行模式请使用 Git 更新。发布缺少可用 EXE 或 SHA256 时不会自动安装。检查与下载只在用户点击时进行，不发送外设清单或采样数据。网络连接本身会向 GitHub 暴露通常的客户端网络信息。当前实验版不会自动降级到更旧正式版；同一版本从实验转为正式发布时可升级。

自动更新依赖下载版本继续兼容 `--apply-update` 协议。154 项回归测试通过，包括校验失败拒绝安装、隔离目录安装/回滚与设置保留；后续真实版本间升级仍需随发布验证。项目当前未对 EXE 做商业代码签名。


v2.4.1 将底部设置整理为两行：开机自启 / 刷新间隔，更新通道 / 当前版本与更新按钮。下载进度仅在下载时展开。


本地真实更新验证已完成：v2.4.0 的更新组件从 GitHub 下载 v2.4.1，实际取消一次后重新下载，通过 SHA256 校验，替换已安装 EXE 并启动新版；设置和自启动配置保持一致。此测试由本地测试程序驱动真实更新组件，非模拟网络或模拟安装。

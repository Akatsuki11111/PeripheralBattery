# PeripheralBattery

Windows 外设电量托盘工具，使用 Python / PySide6。当前双版本：**v2.8.0 正式版**、**v2.8.1-experimental.1 实验版**。

## 下载与使用

从 [GitHub Releases](https://github.com/Akatsuki11111/PeripheralBattery/releases) 下载对应 EXE。正式版不包含电量适配实验和长期观察；实验版保留。两版均支持设备识别、可读电量、充电/连接状态、详情、开机自启和 5/15/30/60 秒刷新。

托盘优先显示最低可信百分比与设备标识。仅有分档数据的手柄如实显示等级，不换算成虚构百分比。休眠设备保留最后有效读数和原采样时间；物理移除后隐藏。品牌识别不代表全部型号均支持电量读取。

## v2.8 修正

- 清理公开材料中的部署信息；公开源码和安装包不内置私人更新连接信息。
- 更新配置由部署者单独提供，保存在 Windows 当前用户受保护目录。未配置时不发起更新请求。配置需要在每台电脑单独导入，已有配置随升级保留。
- 请求认证与安装包发布签名分别校验；RSA/SHA256 验签完成前不执行安装包。更新日志保持普通文字。
- 修正工具按钮点击后残留焦点框的问题，保留键盘焦点提示。
- 后台查询明确采用隐藏、无控制台窗口的启动方式；后台刷新不弹出主界面，稳定布局减少重复调整。

程序没有管理账号、管理口令或发布私钥。受保护的本机配置不属于 EXE 资源。它保护静态部署数据；运行时网络连接仍可被本机用户/管理员观察，不能承诺网络目标永远不可知。

## 设备与验证边界

支持通用 HID 键鼠、有线设备识别、部分品牌专用电量协议，以及 Windows 手柄电池通道。Xbox、Sony、Nintendo、八位堂等模式的来源与限制见 [GAMEPADS.md](GAMEPADS.md)。Xbox 尚无实机验证；驱动不提供电池信息时保持未知，不虚构满电或充电。

M5 Lite 使用已验证的接收器状态与型号字段；USB 占位值和离线缓存不会作为实时电量。未知协议的实验结果仅是线索，不保证观察后一定适配。代码和界面测试不代替每个型号的实测。

## 开发

使用 Python 3.14，安装 `requirements.txt` 后运行 `python app.py`。执行 `python -m unittest discover -s tests` 验证，使用 `build.ps1 -Channel both` 构建双版本。正式版打包排除实验运行模块，源码保留完整构建能力。

部署与发布的通用约定见 [RELEASE_SERVER.md](RELEASE_SERVER.md)。依赖及素材许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。构建体积约 29 MB，精简仍保留原有 Qt、DPI、图标和更新校验能力。无商业代码签名证书。
